# ROBO.400-Exercises
 
Repository for exercises and coursework on ROBO.400 ROS2 and Gazebo robot programming course at Tampere University.

## Developers

 * Eero Rannikko

## Usage

 Individual solutions for the exercises are developed on dedicated branches under exercise specific subfolder, e.g. ex01. After completing and reviewing the solutions together, a solution will be merged on the main branch.
